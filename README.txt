# Construction Empire

A first-version, offline-first personal tracker for a construction learning and business journey.

## Files
- `index.html`: the app
- `manifest.json`: installable web app metadata
- `sw.js`: offline cache service worker
- `icon.svg`: app icon

## Quick start
Open `index.html` in a modern browser to use the app. Records are saved in that browser's local storage on that device.

## Install on Android
For full installable-app and service-worker offline support, publish these files to a secure HTTPS static host. Open the hosted address in Chrome on Android, then use the browser menu and choose **Install app** or **Add to Home screen** (wording varies).

## Backups
Use Settings → Export backup regularly. Keep backup files somewhere safe. Restore replaces the current local records.

## Important
This is a first working prototype, not a regulated construction, accounting, HR or safety-management system. Verify applicable Cambodian legal, engineering, employment, tax and safety requirements with qualified professionals. Do not store sensitive personal data unnecessarily.
